추천의 방향을 뒤집었습니다

대부분의 여행 서비스는 많이 찾는 곳부터 보여줍니다. 그래서 인기 지역은 더 붐비고, 볼거리가 있어도 덜 알려진 지역은 계속 뒤로 밀립니다.

숨은여행지도는 거꾸로 묻습니다. 사람이 적게 가는 곳 가운데 실제로 가볼 만한 곳은 어디일까? 붐비는 여행지에 지친 사람, 남들이 잘 모르는 곳을 찾는 사람을 위한 서비스입니다.

사람은 적게 가지만,
볼 것은 있습니다.

이렇게 사용합니다

  1. 1

    전국 지도 보기

    시군구별 방문량을 색의 농도로 칠합니다. 많이 가는 곳은 진하게, 적게 가는 곳은 연하게 보입니다.

  2. 2

    숨은 지역 고르기

    연한 지역을 누르면 30일 평균 방문량과 전국에서 하위 몇 %인지 알려줍니다.

  3. 3

    사진으로 확인하기

    같은 화면에 그 지역 관광지 사진이 3~6장 나옵니다. 사람은 적어도 볼 것은 있다는 걸 바로 확인할 수 있습니다.

  4. 4

    검색으로 좁히기 여유가 있으면

    계곡, 사찰, 박물관, 바다 같은 키워드로 숨은 지역 안의 관광지를 검색합니다. 검색은 7주차 수업에서 다루는 OpenSearch로 붙입니다.

목업의 수치와 지역 정보는 예시 데이터입니다.

공공데이터 세 가지를 우리 API로 묶습니다

외부 데이터를 화면에서 바로 부르지 않습니다. 한 번 모아 DB에 저장하고, 우리가 만든 FastAPI로 서비스에 필요한 모양만 꺼내 씁니다.

  1. 외부 API한국관광공사, SGIS
  2. 수집기Python
  3. DBPostgreSQL, Supabase
  4. 우리 APIFastAPI
  5. 화면React, Leaflet

점선은 외부 기관이 제공하는 부분, 실선은 팀이 직접 만드는 부분입니다.

숨은 정도는 이렇게 계산합니다

Ghost Index = 100 − 방문량 백분위

전국 시군구를 30일 평균 방문량 순서로 세우고, 적게 방문할수록 높은 점수를 줍니다. 방문량 하위 20%이면서 사진 있는 관광지가 3곳 이상인 지역을 숨은 여행지 후보로 표시합니다.

팀이 탐색용으로 정의한 지표이며, 관광지의 가치를 평가하는 점수가 아닙니다.

우리 API가 하는 일

FastAPI로 만드는 핵심 엔드포인트 다섯 개입니다.

엔드포인트하는 일
GET /regions전국 시군구의 평균 방문량, 백분위, Ghost Index를 돌려줍니다. 지도를 칠하는 데 씁니다.
GET /regions/{code}선택한 지역의 방문량 요약을 돌려줍니다.
GET /regions/{code}/attractions선택한 지역에서 사진이 있는 관광지 목록을 돌려줍니다.
GET /hidden방문이 적고 볼거리가 있는 숨은 지역 목록을 돌려줍니다.
GET /health서버와 DB가 제대로 연결됐는지 확인합니다.

여유가 있으면 관광지명, 주소, 카테고리 검색을 OpenSearch로 추가합니다.

발표까지 4주

  1. 5주차

    데이터 연결 확인

    API 키 발급, 종로구 한 곳을 수집부터 화면까지 연결, 지역 연결표 초안

  2. 6주차

    백엔드 완성

    전국 방문량 수집, 30일 집계와 Ghost Index 계산, 관광지 사진 저장, 핵심 API 완성

  3. 7주차

    화면과 배포

    코로플레스 지도, 지역 상세와 사진 카드, Vercel과 Render, Supabase 배포

  4. 8주차

    최종 발표

    기능 동결, 1분 라이브 데모 반복, 실패에 대비한 캡처와 샘플 응답 준비

8주차 발표에서 보여드릴 것

  • 배포 주소를 열면 전국 지도가 보이고, 지역별 색 농도가 실제 DB 방문량과 연결되어 있습니다.
  • 연한 지역을 누르면 방문량 하위 몇 %인지와 사진 있는 관광지 3곳 이상이 함께 나옵니다.
  • FastAPI 문서 화면(/docs)에서 핵심 API가 정상적으로 응답합니다.
  • 팀원 누구나 외부 API에서 DB, 우리 API, 화면으로 이어지는 흐름을 설명할 수 있습니다.

이번에는 AI 추천, 날씨, 맛집, 숙박, 여행 코스, 개인화를 넣지 않습니다. 기능 수보다 한 흐름이 끝까지 동작하는 것을 먼저 완성합니다.
